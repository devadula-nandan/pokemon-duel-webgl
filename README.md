# Duel Field — Pokémon Duel (WebGL)

A modern Three.js / WebGL recreation of **Pokémon Duel** core rules.

## Run

```bash
cd pokemon-duel-webgl
npm install
npm run dev
```

## Rules

See [RULES.md](./RULES.md) — mechanics aligned to the official Pokémon.com Duel guide (turn structure, colors, statuses, surrounds, PC).

Combat color matrix is covered by `src/game/combat.test.ts` (10 assertions).
